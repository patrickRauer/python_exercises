# Code structure 
Code structure matters for different reasons.
From my experience the most important ones are:
- understandability
- maintainability
- testability

## Naming 
Naming things is hard, using descriptive naming 
is even harder (without writing very long names😉).

But with just a few rules, the naming can be improved 
a lot.
1. start with key verb's
2. use generic names, if it is a generic operation
3. use precise names, if it does one particular thing
4. if you can't sum up the purpose of the function in max four word, split it and try it again
